# Offers And Upsells Workflow

Use this workflow whenever a new client offer is being created or reworked.

## Step-By-Step

1. Define the core pain, desired outcome, and time-to-value.
2. Define the mechanism that makes the offer different from generic alternatives.
3. Build the front-end offer:
   - promise
   - deliverables
   - timeline
   - bonuses
   - proof stack
   - price and guarantee
4. Add the next logical value step:
   - order bump
   - upsell
   - downsell
   - continuity or retention offer
5. Map each offer step to the funnel:
   - opt-in
   - core offer
   - follow-up
   - upsell
   - retention
6. Document objections and the counter-proof used to answer them.
7. Confirm the offer can be sold in ads, on the page, and inside follow-up without changing the core promise.

## Reusable Checklist

- [ ] One primary offer only
- [ ] One clear mechanism
- [ ] Proof exists for the main promise
- [ ] Bonuses support the offer instead of distracting from it
- [ ] Upsell increases speed, depth, or convenience
- [ ] Downsell keeps the same problem but lowers commitment
- [ ] Retention path is explicit after conversion
- [ ] Pricing and payment options are documented

## Store In Client Workspace

- `offers/` for commercial structure
- `flows/` for where each offer step appears
- `landing-pages/` for on-page order and pricing presentation
- `emails/` for follow-up and upsell sequence logic
