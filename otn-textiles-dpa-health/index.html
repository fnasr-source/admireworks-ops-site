01What is happening

The OTN team keeps sending screenshots of ads that look broken. There are actually two different things in those screenshots, and only one of them is a defect.

Expected: raw {{product.name}} in the post story

When a page admin taps into a catalog DPA to view comments, Meta has no product context, so it renders the Liquid template literally. Every catalog DPA in the world looks like this when viewed that way. It does not mean users are seeing it.

Real bug: broken product cards in the feed

The Sep 6 screenshots show a product card with no image and placeholders like {{product.name}} / {{product.current_price}}. This is users actually seeing a broken product from the catalog. It is caused by stale/deleted Shopify variants still present in the Meta catalog.

2. Fix or remove the four broken Shopify variants

  1. Open OTN Shopify admin → Products → “White Set of 6 Wavy Towels”.
  2. For each of the four variants above, either:
    • Set a real name, price in EGP, availability, and upload a working 1080×1080 image, OR
    • Delete / set the variant to draft if it is no longer sold.
  3. Force a Meta catalog sync (Shopify channel → Facebook & Instagram → Sync products), or wait for the next automatic sync and re-check the four product IDs.

3. Optional cleanup

04How to verify

After the fix, confirm both the catalog and the live ads are clean.

Catalog check

Query the product set and confirm every product has:

  • a non-empty name
  • a price starting with EGP, not $0.00
  • availability = in stock or out of stock
  • an image_url that returns HTTP 200

Ad check

For the active DPA, confirm:

  • Creative still points to a product set
  • Effective status is ACTIVE
  • Preview a few cards from the clean set on mobile and desktop
  • Spend continues and CTR does not drop

05Prevent it from recurring

The current weekly DOF watch checks Advantage+ Creative toggles, not catalog health. Add a parallel catalog-health check.

Weekly catalog-health sweep

  1. Pull every product in each DPA product set.
  2. Flag any product missing name, with $0.00 price, empty availability, or a non-200 image_url.
  3. Report the count + retailer IDs to the team Slack/WhatsApp thread.
  4. If count > 0, create a clean set immediately while Shopify is being fixed.
